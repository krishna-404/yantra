### Problem

`.brain/conventions.md`, but `.brain/` doesn't exist yet — every turn runs blind on
locked decisions and repo conventions. (The harness already tolerates the absence;
this task ends it.)

### Bet

If we create the four-file brain skeleton pre-loaded with the locked decisions, every
subsequent advise run cites D-entries in its plans, verifiable by the files existing
and the next advise JSON referencing them.

- [ ] Diff touches only `.brain/**`; all of `yarn lint`, `yarn check-types`, `yarn test:run` green in CI.

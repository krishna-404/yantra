### Problem

doubles test surface and confuses every agent that greps the codebase. Per locked
decision D16 the offline/sync INFRA must survive; only the journal DOMAIN goes. This is
the first link of the B1→B3 backend chain.

backend builds and tests green with no `modules/journal-entries` references, verifiable
by CI + the greps below.

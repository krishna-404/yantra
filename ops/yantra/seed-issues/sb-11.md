### Problem

`apps/frontend/src/modules/journal-entries/` and `apps/frontend/src/modules/prompts/`
are OneQ UI. They pull journal state into routes, nav, and bundles. Per D16 the PWA /
service-worker / worker INFRA stays; only journal UI goes. First link of the frontend
chain (B4), parallel to the backend chain.

### Bet

If we remove the journal and prompts frontend modules and their routes, the app builds
and E2E passes with no journal pages, verifiable by CI + greps below.

### Success criteria

- [ ] `apps/frontend/src/modules/journal-entries/` and `apps/frontend/src/modules/prompts/` deleted.
- [ ] Routes/nav entries referencing them removed; app boots to a working home route (E2E homepage spec green).
- [ ] `grep -ri "journal" apps/frontend/src --include="*.ts" --include="*.tsx" -l` returns ONLY files under `worker/` and `sw/` (SB-12's scope).
- [ ] NOTHING under `apps/frontend/src/worker/`, `apps/frontend/src/sw/` changed (D16).
- [ ] All of: `yarn lint`, `yarn check-types`, `yarn test:run` green in CI; `yarn test:e2e:with-build` green locally (paste tail in PR body).

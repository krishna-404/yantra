### Problem

`packages/zod-schemas/src/` still ships `journal_entry.zod.ts`, `journal_entry.fixture.ts`,
`prompt.zod.ts`, and the `journal-entries/` + `prompts/` dirs. Both consumers (backend
#10, frontend #12) are journal-free now, so these schemas are dead weight and the last
type-level trace of OneQ outside migrations.

### Bet

If we delete the journal/prompt schemas and fixtures, all workspaces build green and
the monorepo-wide journal grep hits only migrations, verifiable by CI + greps below.

### Success criteria

- [ ] `journal_entry.zod.ts`, `journal_entry.fixture.ts`, `prompt.zod.ts`, `journal-entries/`, `prompts/` removed from `packages/zod-schemas/src/`; package index/exports updated.
- [ ] `grep -ri "journal\|prompt" packages/zod-schemas/src --include="*.ts"` → 0 hits.
- [ ] `grep -ri "journal" apps packages --include="*.ts" --include="*.tsx" -l` returns ONLY files under `apps/backend/src/db/migrations/` (SB-14's scope) — 0 other hits.
- [ ] All of: `yarn build`, `yarn lint`, `yarn check-types`, `yarn test:run` green in CI.

### Out of scope

Migrations (#14), seeds/fixtures elsewhere (#15).

### Evaluation

Post-merge canary green. Revert condition: any workspace type-check regression.
